# Интеграция с ядром UWU

Агент — клиент REST API ядра UWU. Контракт ниже зафиксирован в
[`app/clients/uwu.py`](../app/clients/uwu.py) (методы, пути, авторизация) и
соответствует §9 спецификации ядра (`docs/ai-agent.md`).

## Авторизация

API-ключ агента (создаётся в админке ядра `/admin/agent/keys`, хешируется
SHA-256, показывается один раз). Агент передаёт его в заголовке:

```
Authorization: Bearer <UWU_API_KEY>
```

> 🧩 Формат авторизации подлежит подтверждению при реализации зависимости
> API-key в ядре (см. `ROADMAP.md`, фаза 0). Ключ и базовый URL задаются через
> `UWU_API_BASE_URL` / `UWU_API_KEY`.

## Эндпоинты, потребляемые агентом

| Эндпоинт | Метод | Назначение | Статус в ядре |
| --- | --- | --- | --- |
| `/api/agent/inbox` | GET | непрочитанные входящие (polling) | 🧩 этап |
| `/api/agent/messages` | POST | агент публикует ответ (`author="agent"`) | 🧩 этап |
| `/api/agent/context/{chat_id}` | GET | сводка профиль/корзина/история | 🧩 этап |
| `/api/agent/prompts` | GET | активные промпты (кэш агента) | 🧩 этап |
| `/api/agent/tools` | GET | включённые инструменты | 🧩 этап |
| `/api/agent/approvals` | POST | создать запрос одобрения | 🧩 этап |
| `/api/agent/approvals/{id}/decide` | POST | решение оператора | 🧩 этап |
| `/api/agent/runs` | POST | записать результат запуска (аудит) | 🧩 этап |

Tool-friendly эндпоинты чтения (для инструментов): `/api/agent/search_catalog`,
`/api/agent/get_stock`, `/api/agent/get_cart`, `/api/agent/get_zakaz` (только
чтение; запись — через существующие `documents`/`customer` API с одобрением).

## Поток сообщения

1. Ядро уведомляет агента (webhook на `/webhook` или polling `/api/agent/inbox`).
2. Агент выполняет граф (см. [graph](graph.md)).
3. Ответ публикуется через `POST /api/agent/messages`; ядро доставляет его в
   канал через `deliver_outgoing()`.
4. Для действий, требующих одобрения, агент создаёт `AgentApproval`; после
   решения оператора граф возобновляется.

## Управление из админки (уже в ядре)

Промпты, инструменты, ключи, одобрения и наблюдение управляются в админке UWU
(`/admin/agent/*`). Агент загружает промпты/инструменты через API (кэш с
инвалидацией) и не хранит их в своём коде.

## Контракт-тесты

При реализации эндпоинтов ядра контракт-тесты агента (см.
[`tests/test_client.py`](../tests/test_client.py)) фиксируют пути/методы; при
изменении эндпоинта ядра — красный тест в этом репозитории.
